Line spacing and Size for one meeting

Line spacing is the gap between lines on Address Book meeting pages. Size is the contact font size on those pages.

When All Fields or All Meetings is selected, the Line spacing and Size boxes set the book values. Every meeting uses those values unless a meeting has its own setting.

To change Line spacing or Size for just one meeting:

1. Choose that Field in the preview dropdown.

2. Choose that one Meeting — not All Meetings.

3. This meeting appears next to Typography. Size and Line spacing then apply to that meeting.

4. Change the number. Only that meeting updates in the preview and in Print PDF.

5. Click Save to keep the setting.

A small reset at the front of the Size or Line spacing box appears after you change that meeting. Click it to clear the meeting setting and go back to the book value. Setting the number back to the book value does the same thing.

Other meetings keep the book values. Changing the book Line spacing or Size later does not remove a meeting’s own setting. The same meeting name in two Fields can differ. On Complete mtgs/page, meetings that share a page can print at different spacing and size.

Meeting Data Line Spacing and font size are separate and do not change Address Book pages.
