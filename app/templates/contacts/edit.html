Notes

Meets in different state

Used to filter contacts lists on the contact page by state contact attends meeting in rather than state contact lives in.

Notes print codes

Additional info can be printed with the contact with these codes: pb/ or pa/.

pb/ = print before address (same line as name if room)

pa/ = print after address

Example: pb/ Tom is son prints Tom is son before the address lines. Include parentheses in the note to print them, such as pb/ (Tom is son) or pa/ (lives nearby).

Select words in Notes, then press Ctrl+B for bold, Ctrl+I for italic, or Ctrl+U for underline. On a Mac, use the Command key. The same formatting prints on pb/ and pa/ lines. A word that is both bold and italic prints in bold.

Put the caret on a line, then click A− or A+ to decrease or increase that line's font size by 0.5pt. Only the current line changes. The same size prints on pb/ and pa/ lines in the book.
